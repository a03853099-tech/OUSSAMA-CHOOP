مشروع سيرفر إبراهيم وأسامة Free Fire
====================================
يحتوي على:
- موقع ويب عربي متجاوب.
- API مشترك لتسجيل اللاعبين والنقاط والمهام والجوائز.
- SQLite لتخزين البيانات على السيرفر.
- تحديث لحظي باستخدام Socket.IO.
- حالة متصل/غير متصل عبر heartbeat.
- إدارة محمية بكلمة سر موجودة في متغير البيئة ADMIN_PASSWORD.
- رفض طلب الجائزة يرجع النقاط للاعب.

التشغيل محلياً:
1) تحتاج Node.js 20 أو أحدث.
2) افتح مجلد المشروع في Terminal.
3) نفّذ: npm install
4) عيّن ADMIN_PASSWORD إلى كلمة مرور الإدارة التي تريدها.
5) عيّن TOKEN_SECRET إلى قيمة عشوائية طويلة وسرية.
6) عيّن DB_PATH إلى مكان دائم لحفظ قاعدة البيانات، مثلاً ./data.sqlite
7) نفّذ: npm start
8) افتح http://localhost:3000

النشر على Render:
- ارفع محتويات هذا المجلد إلى مستودع GitHub خاص.
- في Render اختر New > Blueprint واربط مستودع GitHub.
- Render يقرأ render.yaml وينشئ خدمة ويب وقرصاً دائماً.
- أدخل ADMIN_PASSWORD في إعدادات Environment عند النشر.
- احتفظ بعنوان الموقع الذي يعطيه Render وشاركه مع اللاعبين.
- خدمة Render والقرص الدائم قد يتطلبان خطة مدفوعة؛ راجع الأسعار الحالية قبل التأكيد.

إعدادات مهمة:
- كلمة مرور الإدارة لا توضع في HTML؛ يجب وضعها في ADMIN_PASSWORD على السيرفر.
- TOKEN_SECRET يولده Render تلقائياً في ملف render.yaml.
- الرقم المستعمل لطلبات الجوائز مضبوط على 212696240414 (صيغة دولية للرقم الذي زودتني به).
- اللاعبين الجدد يسجلون مرة واحدة من جهازهم؛ token يبقى محفوظاً في المتصفح.
- الاسم المسجل مسبقاً لا يمكن تسجيله من جديد من جهاز آخر؛ هذا يمنع انتحال الاسم. لاستعادة حساب ضائع يلزم إجراء إداري/استعادة آمنة لاحقاً.
- الحالة متصل تعني وجود heartbeat خلال آخر 90 ثانية.
- قاعدة البيانات SQLite محفوظة على القرص الدائم المحدد في Render.

تنبيه:
هذا المشروع جاهز كمصدر سيرفر وموقع، لكنه لم يُنشر بعد على الإنترنت. لا يوجد رابط عام قبل ربط GitHub/Render وإكمال النشر. راجع الأسئلة الدينية من مصدر موثوق قبل اعتمادها كمسابقة رسمية.
